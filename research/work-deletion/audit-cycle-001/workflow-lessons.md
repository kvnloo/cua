# Reusable evidence-audit lessons

Recorded in the assigned lane; no cross-profile skill or memory writes.

- Inventory explicit negative controls before designing new ones. Reuse their
  executable tests and distinguish declaration/template counts from executed
  trial counts. Mark corpus replays of registered controls as reuse.
- Audit the intended claim, not merely whether the fixture reached success.
  Exercise the unmodified verifier with a real subprocess and independent HTTP
  fixture, then deliberately decouple claimed actions from actual submission.
- Treat nonempty session labels and unequal refs as assertions until bound to
  independently captured observations and actual dispatch arguments.
- Count actual chooser/provider entrypoints independently. Rounded decision
  durations, especially zero, establish neither presence nor absence of calls.
- Preserve incomplete historical receipts. Missing per-trial counters or
  dispatch witnesses must remain missing; new FIX captures cannot qualify old
  REAL rows by association.
- Keep a claim separate from caller-owned witness custody. Corrupt both redundant
  telemetry copies when testing semantics, and separately corrupt witness bytes
  under unchanged trusted hashes. Otherwise copy comparison or hash failures
  can conceal missing semantic validation.
- Persist only comparison booleans for field values, never field contents or
  per-value hashes. Record redacted refs, sessions, chronological counter events,
  explicit fallback reasons and stable cell/trial attribution.
- Remove inherited Python module-path overrides when reusing a read-only venv.
  Invoke nested TypeScript tests with a known Node and audit-local dependency
  resolution; disable compiler caches and remove temporary links in finally.
- For this environment, never use cached global browser/computer-use Driver
  tools to test input. Keep evidence audits hermetic. Any separately authorized
  GUI/input lane must be parent-owned, verified headless Sway-wm only, with no
  native Hyprland or Xvfb fallback.
