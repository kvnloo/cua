## Every cycle

1. Sync/read current trycua/cua main, RFC #3963, relevant owner PRs/issues, maintainer comments, downstream evidence and Driver/jev-use contracts. Record exact upstream/source SHA, source links, and changed-contract reconciliation before measuring.
2. Regenerate candidates simultaneously from surviving top-down claims, actual whole-task traces, and adversarial counterexamples. Dedupe scientific cells against completed evidence.
3. Rank approximately by decision relevance x information gain x claims affected x falsification power x reproducibility / implementation cost / runtime cost / confounding. Explicit maintainer requests and sequential qualification dependencies override the rough score.
4. Execute the highest-value sequential blocker and independent cheap lanes. Prefer existing artifacts, replay, fixture/configuration mutation and deterministic failure/delay injection before product changes. Use exhaustive authority boundaries, mixed-strength/3-way interaction coverage, pairwise compatibility and paired performance trials; do not execute a blind Cartesian product.
5. Have an independent auditor re-execute/check the exact receipts, negative controls and hashes. Classify KEEP / NARROW / REVISE / KILL / NEEDS_REPLICATION / BLOCKED. A successful task without proof of the intended actual optimization path is NONQUALIFYING.
6. Update frontier cells, counterexamples, work counts, cost regions, platform scope, unsafe regions and duplicates; commit coherent evidence/tooling normally downstream when useful. Recompute priorities and begin the next cycle immediately.

## Promotion law and receipt

Qualifying evidence establishes forced path -> actual executed path -> admission/proof facts -> independent oracle -> explicit decline/fallback. A negative control must demonstrate that corrupt evidence makes the checker fail. Time rounded to zero is NOT a provider invocation counter.

Each receipt needs claim/falsifier, exact upstream/source/tooling identities, environment/platform/language/provider, workload/factors, path forcing and observed execution, authorization/refusal facts, independent state/journal oracle, fallback, negative-control result, named timing spans, work counters, verified outcome, invariant violations, artifact hashes and exact reproduction command.

Stable cell_key identifies scientific conditions; trial_key identifies an individual execution. Repeated execution of one cell is replication, not new coverage. Do not persist secrets or protected field contents; store status/booleans/counts/refs instead. Old #10 trace harness stores command tokens, fixture values and raw MCP messages and must not be reused unchanged.

Structural deletion priority: model decisions -> steps -> observations/producers -> waits -> redundant verification -> micro-latency. Primary timing endpoint is independently verified outcome. Cold startup, runner lifetime and cleanup remain separate. Count actual producer work, not requested selector names. Report critical-path interval union rather than summing overlapping spans; expose residual and unknown coverage.

## Safety and containment

Never accept stale refs, cross-session authority, capture mismatch, ambiguous rebinding, blind replay of may-have-landed mutation, passive observations creating mutation authority, or event absence as proof of unchanged state. One optimization-caused stale/wrong mutation is a critical falsifier. Keep semantic continuation separate from #2794 mechanical batching.

Recipe-local/test-local and opt-in. No competing DecisionService, RouterService, PostconditionService, universal shadow-state/lifecycle service, fixed-length GuardedRun or batch API. Genuine Driver/product contract changes require escalation, not speculative implementation.
