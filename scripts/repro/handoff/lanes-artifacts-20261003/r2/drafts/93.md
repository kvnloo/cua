## Research round 2: P0 results (R2-01 to R2-06), 2026-10-01

Each experiment ran in its own private rootless Xvfb + dbus session (with AT-SPI for R2-04) on one Linux host with Chrome 151. Each packet was then checked by a separate fresh verifier, which recomputed every number from `raw/` and re-ran a few trials of its own. All six were accepted. No experiment added a service, and no Driver default changed. Instrumentation is measurement-only and env-gated, and it is off unless that variable is set. **RFC delta: none.**

### Cross-cutting findings

- **Visual feedback is the largest named cost on both surfaces we measured.** On the browser it is causal (R2-01). On the GTK3 native route it is localized but not yet tested causally (R2-04). In R2-06 the trusted pointerdown arrives ~1.58 s into a ~1.61 s span, which is consistent but descriptive only.
- **Re-read the oracle with a bounded loop after any accepted mutation, on any route.** In R2-06, 25/30 dom_event POSTs also landed after the tool returned. R2-01 and R2-02 saw the effect land +0.3 to +1 ms after return. A first negative read is `unknown`. It is never permission to replay (R2-05).
- **An event wake does not pay off when the effect already lands at return** (R2-02 KILL). Events stay wake hints only.
- **Possible Driver truthfulness issue (R2-06, SOURCE + REAL):** a foreground trusted `browser_click` returns `delivery:{mode:"background"}`. The cause is that `action_record.rs` `actual_delivery_from_legacy` hard-codes `Background`.
- **Suspected per-call CDP session accumulation (R2-02, SOURCE only, unverified):** event volume grows by one unit per tool call, and no detach was found on that path.

### P1 after P0

- **R2-07:** unblocked. Its harness must reconcile a may-have-landed mutation before fallback, because the kvnloo/cua#105 runner does not. It must also hold feedback fixed across arms.
- **R2-08:** independent of P0.
- **R2-09:** deprioritized. The GTK3 fixture has no wait on the caller side, so the only candidate is the Driver-internal 50 ms post-`DoAction` sleep, and only after a causal A/B.
- **R2-10:** unblocked as a 2×2 (guarded completion × feedback on/off) on one source. Candidates dropped: CDP commit wake, and AT-SPI bulk for small trees.
